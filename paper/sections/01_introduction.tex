\section{Introduction}

Fine particulate matter (PM2.5) is a major urban air-quality risk because it is
associated with respiratory and cardiovascular health effects
\cite{who2021airquality}. Accurate short-term PM2.5 forecasts can support
public-health alerts, exposure reduction, transport planning, and environmental
operations. In Los Angeles County, however, PM2.5 dynamics are difficult to
model with pollutant history alone. Concentrations can change with wind speed,
boundary-layer behavior, rainfall, seasonal activity, holidays, wildfire smoke,
and unusual storm or high-wind events. These factors make the forecasting problem
both temporal and contextual.

Recent time-series foundation models (TSFMs) aim to improve forecasting
generalization by pre-training on large time-series corpora and transferring the
learned forecasting ability to new domains. Representative models include
TimesFM, Moirai, MOMENT, Chronos, and Tiny Time Mixers
\cite{das2024timesfm,woo2024moirai,goswami2024moment,ansari2024chronos,ekambaram2024ttm}.
In parallel, retrieval-augmented generation has shown that non-parametric memory
can help foundation models access relevant external knowledge at inference time
\cite{lewis2020rag,karpukhin2020dpr}. TimeRAF combines these two ideas for
zero-shot time-series forecasting by retrieving relevant historical sequences
from a curated knowledge base and integrating them into a frozen TSFM through
Channel Prompting \cite{zhang2025timeraf}.

Air-quality forecasting raises a domain-specific retrieval question that is not
fully addressed by numerical time-series retrieval alone. A historical PM2.5
window may look similar to the current window but occur under different weather
or event conditions. Conversely, a window with moderate numerical similarity may
be more informative if it shares high-wind, rainfall, holiday, smoke, or
stagnation context. This motivates a retrieval framework that treats source
records, weather, calendar information, and distribution-shift indicators as
part of the forecasting evidence rather than as unrelated metadata.

This paper introduces Event-TimeRAF, an event-aware retrieval-augmented
framework for explainable PM2.5 forecasting under concept drift. The design is
inspired by TimeRAF, but it is adapted to an official-source environmental
forecasting setting. The implemented system uses leakage-safe retrieval over
historical PM2.5 windows, weather and calendar context, source-recorded NOAA
Storm Events, transparent drift indicators, direct XGBoost forecasters, a frozen
Chronos-Bolt baseline, and evidence-grounded explanations. The framework
answers three practical questions: (1) how can official environmental records be
converted into a retrieval-compatible knowledge base; (2) how should retrieval
be constrained so that future target information is not leaked; and (3) when
does retrieval help beyond strong weather-calendar supervised baselines?

The main contributions are as follows:
\begin{itemize}
    \item We formulate an event-aware retrieval-augmented PM2.5 forecasting
    framework that combines time-series windows, weather summaries, calendar
    context, storm-event records, and drift indicators.
    \item We implement a reproducible official-source pipeline using EPA
    AirData PM2.5, NOAA Global Hourly weather, and hash-verified NOAA Storm
    Events records for Los Angeles County during 2019--2024.
    \item We define leakage-safe retrieval eligibility rules that prevent
    candidate windows from overlapping the query context or future target.
    \item We evaluate random retrieval, cosine retrieval, event-aware hybrid
    retrieval, drift-aware feature fusion, frozen Chronos-Bolt, and
    retrieval-augmented Chronos-Bolt under a controlled evaluation protocol.
    \item We report a conservative empirical finding: retrieval improves the
    frozen Chronos-Bolt MSE slightly, but the best overall model is a strong
    XGBoost weather-calendar context baseline.
\end{itemize}

The findings therefore do not indicate uniform gains from retrieval. Instead,
the evaluation identifies the settings in which event-aware retrieval is useful,
the settings in which it is not, and the additional evidence required before
the method can support operational event-aware air-quality forecasting.
